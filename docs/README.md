# docs/ — project assets

Place the README teaser media here:

- **`teaser_sim.gif`** — simulation teaser (Hollywood-poster servoing)
- **`teaser_real.gif`** — real-world teaser (real-robot category-level grasping)

Then update the teaser table near the top of [`../README.md`](../README.md) to embed them, e.g.:

```html
<img src="docs/teaser_sim.gif" width="100%">
```

GitHub also renders an uploaded `.mp4` via a `<video>` tag — drag-and-drop the file into
the README editor on github.com and paste the generated tag into the teaser table.

Longer / additional videos live on the [project page](https://art-vs.github.io/).
